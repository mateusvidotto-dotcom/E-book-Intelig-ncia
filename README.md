# Como Ser uma Pessoa Inteligente — versão aprimorada

Esta é uma reformulação da página publicada em:
https://mateusvidotto-dotcom.github.io/E-book-Intelig-ncia/

## Arquivos

- `index.html`: estrutura e conteúdo da página.
- `styles.css`: identidade visual, componentes e layout responsivo.
- `script.js`: pesquisa, menu móvel, tema, progresso local e botão de compra.
- `favicon.svg`: ícone do site.

## Como publicar no GitHub Pages

1. Faça uma cópia de segurança do repositório atual.
2. Envie os quatro arquivos acima para a raiz do repositório `E-book-Intelig-ncia`, substituindo o `index.html` antigo e adicionando os três arquivos novos.
3. **Não apague `CAPA.png`**. A nova página utiliza esse arquivo como capa e exibe uma capa tipográfica de reserva se ele não estiver presente.
4. No começo de `script.js`, substitua `const PURCHASE_URL = '';` pelo endereço real do checkout. Enquanto o endereço estiver vazio, o botão não inventa um destino e informa que falta configurar o checkout.
5. Confirme que o GitHub Pages continua publicando a branch `main` a partir da raiz do repositório.

## Teste local

Abra `index.html` no navegador. Para testar todos os recursos, mantenha `CAPA.png` na mesma pasta. O site não exige npm, compilação ou bibliotecas JavaScript externas. As fontes Google são opcionais; se não carregarem, há fontes alternativas locais.

## Observações de conteúdo

A estrutura mantém as 13 partes, os assuntos apresentados no site original e a contagem anunciada de 87 capítulos. Os nomes individuais dos 87 capítulos não foram inventados: o site publicado não os exibe integralmente. A afirmação absoluta “100% Base Científica” foi substituída por uma descrição mais cuidadosa, sem prometer aumento de QI ou resultados garantidos.
